# Fixation-Stimulus (FiSt) module for mirror-based adaptive optics scanning systems

This repository contains all the files related to the FiSt module to recreate it for your own use. The main goal of the module is to work as a stand-alone unit to be incorporated to existing imaging systems and allow precise stimulus delivery for optoretinographic measurements. The folders contain STL files that can be directly 3D printed, STP files that allow you to modify components according to your needs and Zemax files to simulate the fixation and stimulus path separately when altering components.

## 1. 3D-printing
There are no restrictions what type of printing method you use or what type of filament. The Gen 1 module was printed using black PLA filament. We also recommend using high enough infill to ensure the rigidity of the different parts. And if you are not familiar with using thread inserts, we recommend printing a test block and practice. It is not difficult, but better to ruin a small sample block than ready-make larger component.

## 2. CAD design
Besides just the STL files, the folders contain also STP files that are meant for the community to develop further. If you make new version of certain components or add something useful, feel free to send us the files and we are more than happy to then include them in this repository.

## 3. Zemax simulations
The current two files (.zmx) simulate the fixation path and stimulus path separately using the currently selected components.
